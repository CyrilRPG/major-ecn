HTA secondaire endocrine et hypoglycémie

  • Évoquer une HTA secondaire devant : sujet jeune, HTA sévère ou résistante, hypokaliémie, ou signes cliniques évocateurs.
  • Hyperaldostéronisme primaire (Conn) = HTA + hypokaliémie ; diagnostic sur le rapport aldostérone/rénine élevé ; traitement chirurgical (adénome) ou spironolactone (hyperplasie).
  • Phéochromocytome = HTA paroxystique + triade de Ménard (céphalées, sueurs, palpitations) ; diagnostic sur les métanéphrines ; chirurgie après alpha-blocage (jamais de β-bloquant seul).
  • Syndrome de Cushing = HTA + obésité facio-tronculaire, vergetures pourpres ; cortisol libre urinaire et test de freinage.
  • Hypoglycémie affirmée par la triade de Whipple ; cause fréquente = iatrogène chez le diabétique (insuline, sulfamides) ; sinon insulinome (insuline + peptide C hauts).
  • Urgence : resucrage oral (15 g de sucre) si conscient ; G30 % IV ou glucagon si troubles de conscience.

À retenir absolument

  • HTA + hypokaliémie → penser Conn ; HTA paroxystique + triade de Ménard → penser phéochromocytome.
  • Dans le phéochromocytome, ne jamais débuter un β-bloquant avant l'alpha-bloquant (risque de poussée hypertensive).
  • Toute suspicion d'hypoglycémie chez un patient inconscient impose un G30 % IV ou glucagon sans délai après confirmation glycémique.
