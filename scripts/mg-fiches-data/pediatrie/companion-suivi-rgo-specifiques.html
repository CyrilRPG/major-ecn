Suivi médical, RGO et pathologies spécifiques

  • Suivi : 20 examens, 3 certificats obligatoires (8e jour, 9e mois, 24e mois) ; dépistage de l'autisme au 24e mois.
  • PMI avant 6 ans, santé scolaire après ; carnet de santé = courbes de croissance + vaccinations.
  • RGO physiologique = régurgitations sans effort ; PEC = RHD + épaississement du lait, IPP seulement si œsophagite/RGO acide prouvés.
  • pH-métrie inutile si régurgitations isolées ou œsophagite prouvée.
  • Maladie cœliaque : gluten, HLA DQ2, cassure pondérale + diarrhées ; IgA anti-transglutaminase → éviction à vie.
  • Maltraitance : 75 % < 3 ans, syndrome de Silverman ; bébé secoué = HSD + hémorragies rétiniennes ; signalement CRIP/Parquet.

À retenir absolument

  • 3 examens obligatoires avec certificat : 8e jour, 9e mois, 24e mois.
  • RGO : RHD d'abord ; IPP inefficaces sur les régurgitations.
  • Convulsion non fébrile < 1 an ou hémorragies rétiniennes profuses = évoquer la maltraitance (bébé secoué).
