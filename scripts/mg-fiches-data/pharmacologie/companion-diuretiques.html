Diurétiques de l'anse (furosémide, bumétanide)Anse de Henlé (branche ascendante large) : inhibition du co-transporteur Na-K-2Cl — les plus puissants, natriurétiques rapidesOAP, insuffisance cardiaque congestive, surcharge hydrosodée de l'insuffisance rénale (efficaces même si DFG bas)

Épargneurs de potassium — non antialdostérone (amiloride)Tube collecteur : blocage du canal sodique épithélial (ENaC) — épargne le potassiumCorrection / prévention de l'hypokaliémie, souvent associé aux thiazidiques

Effets indésirables : le profil dépend du site d'action

Anse et thiazidiquesHypokaliémie (risque de torsades de pointes), hyponatrémie, déshydratation extracellulaire, insuffisance rénale fonctionnelle (hypovolémie), hyperuricémie (goutte), alcalose métabolique

Fiche éclair

Diurétiques

  • Diurétiques de l'anse (furosémide) : agissent sur l'anse de Henlé (Na-K-2Cl), les plus puissants ; indications OAP, insuffisance cardiaque et surcharge de l'insuffisance rénale.
  • Thiazidiques (hydrochlorothiazide) : agissent sur le tube distal (Na-Cl) ; indication de référence l'HTA, inefficaces si insuffisance rénale sévère.
  • Épargneurs de potassium : spironolactone = antialdostérone (tube collecteur), amiloride = blocage d'ENaC ; natriurèse faible mais rétention de K+.
  • Effets indésirables anse + thiazidiques : hypokaliémie, hyponatrémie, déshydratation, insuffisance rénale fonctionnelle, hyperuricémie ; épargneurs = hyperkaliémie.
  • Surveillance systématique : ionogramme + créatininémie à l'instauration puis régulièrement.
  • Interactions à risque : épargneur + IEC/ARA2 (hyperkaliémie), diurétique + AINS + IEC (insuffisance rénale fonctionnelle).

À retenir absolument

  • Anse (furosémide) = puissant, OAP/IC ; thiazidique = HTA ; spironolactone = antialdostérone épargneur de potassium.
  • Anse et thiazidiques donnent une hypokaliémie ; les épargneurs donnent une hyperkaliémie.
  • Surveillance obligatoire : ionogramme sanguin + créatininémie ; méfiance sur les associations avec IEC/ARA2 et AINS.
