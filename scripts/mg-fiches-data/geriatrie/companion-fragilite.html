Personne âgée malade et fragilité

  • Chez le sujet âgé, les maladies ont une présentation atypique (chute, confusion, AEG, refus alimentaire) sur un terrain de polypathologie et de polymédication (iatrogénie +++).
  • Un facteur déclenchant unique peut entraîner une cascade gériatrique (infection → confusion → chute → alitement → escarre → dénutrition → dépendance).
  • Toute décompensation d'organe se lit selon le modèle 1 + 2 + 3 de Bouchon : vieillissement (1) + maladie chronique (2) + facteur déclenchant aigu (3), ce dernier étant la cible thérapeutique prioritaire.
  • La fragilité est un état de vulnérabilité réversible, intermédiaire entre robustesse et dépendance.
  • Phénotype de Fried = 5 critères : perte de poids, épuisement, faiblesse (force de préhension), lenteur de marche, sédentarité ; ≥ 3 = fragile, 1-2 = pré-fragile.
  • Repérage précoce (Gérontopôle, SEGA, vitesse de marche) puis évaluation gériatrique standardisée (ADL/IADL, MMSE, GDS, MNA).
  • Prévention de la perte d'autonomie : activité physique adaptée, nutrition protéino-énergétique + vitamine D, déprescription, correction sensorielle, lien social.

À retenir absolument

  • Sujet âgé = présentation atypique + polypathologie + iatrogénie ; décompensation = 1 + 2 + 3 de Bouchon.
  • Fragilité = état réversible ; critères de Fried (5), ≥ 3 = fragile.
  • Repérer tôt (EGS) et prévenir la perte d'autonomie : activité physique, nutrition, déprescription.
