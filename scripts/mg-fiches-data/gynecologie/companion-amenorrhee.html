Fiche éclair

Aménorrhée

  • Aménorrhée = absence de règles. Primaire : absence de ménarche > 15 ans ; secondaire : arrêt des règles > 3 mois chez une femme antérieurement réglée.
  • Devant toute aménorrhée : éliminer une grossesse en premier par les βhCG, avant tout autre bilan.
  • La démarche repose sur les gonadotrophines (FSH/LH) : élevées → cause ovarienne (hypergonadotrope) ; basses/normales → cause hypothalamo-hypophysaire (hypogonadotrope).
  • Aménorrhée primaire : causes basses utéro-vaginales (syndrome de Rokitansky, imperforation hyménéale) et hautes (dysgénésie gonadique / Turner 45,X, causes centrales / Kallmann).
  • Aménorrhée secondaire : grossesse, SOPK, hyperprolactinémie (adénome), insuffisance ovarienne prématurée, cause hypothalamique fonctionnelle (anorexie, sport), synéchies.
  • Bilan : βhCG, FSH, LH, œstradiol, prolactine, TSH ; imagerie selon l'orientation : IRM hypophysaire, échographie pelvienne, caryotype.

À retenir absolument

  • Devant toute aménorrhée, le premier réflexe est de doser les βhCG pour éliminer une grossesse.
  • L'orientation étiologique se fait sur les gonadotrophines : FSH/LH élevées = origine ovarienne, FSH/LH basses = origine centrale.
  • Aménorrhée primaire avec caractères sexuels secondaires normaux et absence d'utérus = syndrome de Rokitansky ; petite taille + impubérisme = Turner.
