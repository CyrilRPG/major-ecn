Antidépresseurs & anxiolytiques

ClassePoints clés
ISRS (1re intention)Bonne tolérance, faible létalité en surdosage ; effets : troubles digestifs, dysfonction sexuelle, hyponatrémie, risque hémorragique ; surveiller la levée d'inhibition (majoration transitoire du risque suicidaire)
IRSNaVenlafaxine, duloxétine ; efficacité comparable ; surveiller la pression artérielle (effet noradrénergique)
TricycliquesEffets anticholinergiques, cardiotoxicité (troubles du rythme/conduction) ; toxicité majeure en surdosage ; ECG avant prescription
Syndrome sérotoninergiqueUrgence : agitation/confusion + hyperthermie + tremblements/myoclonies/hyperréflexie + signes végétatifs ; risque avec association d'agents sérotoninergiques (IMAO+++)
BenzodiazépinesAnxiolytique/hypnotique ; durée limitée (≤ 12 semaines) ; risque de dépendance, sédation, chutes, troubles mnésiques ; arrêt progressif (sevrage : anxiété rebond, insomnie, convulsions)

Antipsychotiques & thymorégulateurs

ClassePoints clés
Antipsychotiques typiquesAntagonistes D2 ; effets extrapyramidaux marqués : dystonie aiguë, syndrome parkinsonien, akathisie, dyskinésies tardives ; hyperprolactinémie
Antipsychotiques atypiquesMoins d'effets extrapyramidaux ; syndrome métabolique (prise de poids, diabète, dyslipidémie) ; clozapine = agranulocytose (NFS régulière)
Syndrome malin des neuroleptiquesURGENCE vitale : hyperthermie + rigidité + troubles de conscience + dysautonomie + CPK élevées ; arrêt immédiat du neuroleptique, réanimation
LithiumThymorégulateur de référence ; marge thérapeutique étroite ; surveillance de la lithémie, fonction rénale et thyroïdienne ; tératogène
Toxicité au lithiumTroubles digestifs, tremblements, ataxie, confusion, convulsions ; favorisée par déshydratation, AINS, IEC, régime hyposodé

Troubles des conduites alimentaires

TroublePoints clés
Anorexie mentaleRestriction alimentaire avec IMC bas (dénutrition), peur de grossir, distorsion de l'image du corps, aménorrhée ; touche surtout l'adolescente/jeune femme
BoulimieCrises de frénésie alimentaire + comportements compensatoires (vomissements, laxatifs, jeûne, exercice) ; poids souvent normal ; sentiment de perte de contrôle
Hyperphagie boulimiqueCrises sans compensation ; surpoids/obésité fréquents ; souffrance psychique, culpabilité
Complications somatiquesAnorexie : troubles hydroélectrolytiques, bradycardie/hypotension, ostéoporose, syndrome de renutrition inappropriée ; boulimie : hypokaliémie, œsophagite, érosions dentaires, hypertrophie parotidienne
Prise en chargePluridisciplinaire (somatique + nutritionnelle + psychiatrique) ; contrat de poids, psychothérapie ; hospitalisation si critères de gravité (IMC très bas, troubles ioniques, bradycardie, risque suicidaire)

Psychotropes et troubles des conduites alimentaires

  • ISRS = antidépresseur de 1re intention (bonne tolérance) ; tricycliques = cardiotoxiques et toxiques en surdosage ; surveiller la levée d'inhibition.
  • Syndrome sérotoninergique = agitation + hyperthermie + myoclonies/hyperréflexie + dysautonomie (association d'agents sérotoninergiques).
  • Benzodiazépines : durée limitée, risque de dépendance, arrêt progressif (sevrage : convulsions).
  • Antipsychotiques : typiques = effets extrapyramidaux ; atypiques = syndrome métabolique ; le syndrome malin des neuroleptiques (hyperthermie + rigidité + CPK↑) est une urgence vitale.
  • Lithium : marge étroite, surveillance de la lithémie, rein et thyroïde ; toxicité favorisée par déshydratation/AINS/régime hyposodé.
  • Anorexie = IMC bas + peur de grossir + aménorrhée ; boulimie = crises + compensation ; hyperphagie = crises sans compensation.
  • PEC des TCA pluridisciplinaire ; attention au syndrome de renutrition inappropriée et aux troubles ioniques.

À retenir absolument

  • Trois urgences psychopharmacologiques : syndrome sérotoninergique, syndrome malin des neuroleptiques, toxicité au lithium.
  • Lithium = surveillance de la lithémie (marge thérapeutique étroite) ; benzodiazépines = durée limitée et risque de dépendance.
  • TCA : rechercher les complications somatiques (troubles ioniques, cardiaques) et la renutrition inappropriée ; PEC pluridisciplinaire.
