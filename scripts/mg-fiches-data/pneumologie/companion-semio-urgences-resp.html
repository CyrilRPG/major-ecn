Sémiologie et urgences respiratoires

  • Dyspnée aiguë : le temps du cycle allongé oriente (inspiratoire = VAS, expiratoire = bronches).
  • Hémoptysie : origine sous-glottique ; 1re cause = cancer bronchique ; scanner injecté.
  • Douleur thoracique : 5 urgences = SCA, EP, dissection, tamponnade, pneumothorax.
  • EP : probabilité → D-dimères → angioscanner ; D-dimères = forte VPN.
  • Pneumothorax compressif = exsufflation sans attendre l'imagerie.

À retenir absolument

  • Objectif SpO2 : 88-92 % chez le BPCO (sinon ≥ 94 %).
  • Des D-dimères négatifs (probabilité non forte) éliminent l'EP.
  • Hémoptysie grave → artério-embolisation bronchique.
