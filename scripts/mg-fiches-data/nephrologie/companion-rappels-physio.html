Rappels physiologiques

  • Néphron = glomérule + tubule ; débit sanguin rénal = 20–25 % du débit cardiaque ; DFG ≈ 120 mL/min.
  • Rein = homéostasie hydro-électrolytique et acido-basique, volémie, épuration + fonctions endocrines (vitamine D active, EPO, rénine).
  • SRAA : rénine → angiotensine I → (ECA) → angiotensine II → aldostérone (vasoconstriction + rétention hydrosodée).
  • DFG estimé par CKD-EPI 2021 (référence, sans ethnie) ; Cockcroft obsolète ; iohexol si certitude requise.
  • BU = albumine (négative si chaînes légères) ; protéinurie quantifiée par ratio protéinurie/créatininurie ; hématurie confirmée par ECBU.
  • Iono urinaire oriente l'IRA : Na < 20, Na/K < 1, FE urée < 30 % = fonctionnelle.

À retenir absolument

  • Formule de référence du DFG = CKD-EPI 2021, sans facteur ethnie (Cockcroft abandonné).
  • La BU ne détecte que l'albumine : fausse négative devant une protéinurie de chaînes légères (myélome).
  • Avant toute PBR : écho rénale, hémostase et TA contrôlée ; décubitus strict 24h après.
