Grippe

ItemPoints clés
VirologieMyxovirus influenzae (Orthomyxoviridae), 3 types : A (réservoir aviaire), B, C ; glycoprotéines de surface hémagglutinine (HA) et neuraminidase (NA) ; transmission par gouttelettes et manuportage ; saison novembre à février
CliniqueIncubation 1-3 j, contagiosité 1 j avant à 6 j après ; invasion brutale (malaise fébrile, frissons, myalgies, céphalées) ; état : fièvre 39-40 °C, toux sèche ; asthénie résiduelle prolongée
ComplicationsPneumonie bactérienne secondaire (S. aureus, S. pneumoniae, à J5-7) ; grippe maligne primaire (SDRA) ; myocardite, encéphalite ; syndrome de Reye (enfant + aspirine)
TraitementSymptomatique (paracétamol, repos, hydratation) ; inhibiteurs de la neuraminidase (oseltamivir PO) dans les 48 premières heures ; vaccination annuelle +++ (prévention)

Infection VIH

ItemPoints clés
TransmissionSexuelle ++, sanguine (AES, partage de matériel d'injection), materno-fœtale ; risque majoré si charge virale élevée, IST associée, lésion génitale
Primo-infection10-15 j après contage : syndrome rétroviral aigu (fièvre, pharyngite, myalgies), exanthème maculopapuleux, polyadénopathies ; biologie : leucopénie-thrombopénie, cytolyse, syndrome mononucléosique
DiagnosticELISA combiné (Ac + Ag p24), confirmation par Western Blot sur 2e prélèvement ; primo-infection = ARN VIH plasmatique ; bilan : CD4 + charge virale + génotype de résistance + HLA-B*5701
Infections opportunistesPneumocystose (CD4 < 200 : verre dépoli, Bactrim forte dose 21 j) ; tuberculose (quel que soit le taux de CD4) ; prophylaxie primaire par Bactrim si CD4 < 200
TraitementTrithérapie pour tous quel que soit le taux de CD4, à vie ; objectif CV indétectable (< 50 copies/mL) et CD4 > 500 ; prévention : TPE, PrEP (ténofovir + emtricitabine), DO anonyme

Syphilis, zoonoses & fièvre au retour de voyage

ItemPoints clés
SyphilisTreponema pallidum, IST sexuelle +++ (HSH, co-infection VIH) ; primaire = chancre induré indolore unique + ADP satellite ; secondaire = roséole, syphilides palmo-plantaires, collerette de Biett
Diagnostic & traitement syphilisSérologie TPHA (spécifique) + VDRL (non spécifique) ; PL si suspicion de neurosyphilis ; traitement = benzathine pénicilline G IM (1 injection si précoce, 3 si tardive) ; réaction de Herxheimer
ZoonosesMaladie de Lyme (Borrelia, tiques Ixodes, érythème migrant pathognomonique) ; pasteurellose (morsure de chat, amoxicilline) ; maladie des griffes du chat (Bartonella henselae, ADP)
TIAC≥ 2 cas groupés d'origine alimentaire commune, DO obligatoire ; syndrome dysentérique (Salmonella, Campylobacter) vs cholériforme (S. aureus 2-4 h) ; conserver les aliments, coproculture, déclaration ARS
Fièvre au retour des tropiquesPaludisme toujours évoqué en premier ; < 7 j : dengue ; 7-14 j : paludisme, fièvre typhoïde (Salmonella Typhi, pouls dissocié, fièvre en plateau) ; signes hémorragiques → FHV, isolement strict

Grippe, VIH, syphilis, zoonoses et fièvre au retour de voyage

  • Grippe : oseltamivir utile seulement dans les 48 premières heures ; vaccination annuelle ; surinfection à S. aureus / pneumocoque vers J5-7.
  • VIH — diagnostic : ELISA combiné (Ac + Ag p24) puis Western Blot ; primo-infection = ARN VIH si sérologie négative.
  • VIH — traitement : trithérapie pour tous, à vie ; objectif CV indétectable ; Bactrim si CD4 < 200 (pneumocystose).
  • Syphilis : chancre indolore, TPHA + VDRL, benzathine pénicilline G IM, réaction de Herxheimer.
  • Lyme : érythème migrant pathognomonique, tiques Ixodes.
  • TIAC = ≥ 2 cas groupés, DO obligatoire ; retour des tropiques → paludisme d'abord.

À retenir absolument

  • Devant une fièvre au retour de zone tropicale, éliminer le paludisme en urgence avant tout.
  • VIH : trithérapie pour tous, objectif charge virale indétectable ; dépistage par ELISA combiné.
  • Syphilis et TIAC sont des infections à déclaration ; le traitement de la syphilis repose sur la benzathine pénicilline G.
