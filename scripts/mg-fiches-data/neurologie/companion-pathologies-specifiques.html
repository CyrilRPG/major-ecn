Sclérose en plaques : repères diagnostiques et thérapeutiques

ItemPoints clés
TerrainMaladie inflammatoire démyélinisante du SNC ; adulte jeune 20–40 ans, prédominance féminine (70 %) ; gradient Nord > Sud
Clinique révélatriceNORB dans 25 % (BAV unilatérale, douleur à la mobilisation oculaire, dyschromatopsie rouge/vert), signes pyramidaux, troubles sensitifs, signe de Lhermitte
Diagnostic (McDonald)Dissémination spatiale + temporelle ; IRM : hypersignaux T2/FLAIR (périventriculaire ++, juxtacortical, cérébelleux, médullaire), prise de gadolinium si lésion < 3 mois ; LCS : bandes oligoclonales
Formes évolutivesRémittente récurrente (85 %), secondairement progressive (40–50 %), progressive primaire (15 %)
TraitementPoussée : corticoïdes 1 g/j IV × 3 j ; fond 1re ligne : IFN-bêta, acétate de glatiramère, tériflunomide, diméthyl fumarate ; 2e ligne : natalizumab, fingolimod, mitoxantrone

Pathologies neurologiques spécifiques

  • SEP : femme jeune, dissémination spatiale + temporelle (McDonald) ; IRM (hypersignaux T2 périventriculaires) + BOC dans le LCS ; poussée = corticoïdes IV fortes doses.
  • Alzheimer : 1re démence ; trouble mnésique non amélioré par l'indiçage, atrophie hippocampique ; TAU + plaques amyloïdes.
  • Corps de Lewy : hallucinations visuelles + syndrome parkinsonien + fluctuations ; neuroleptiques contre-indiqués.
  • Compression médullaire = urgence ; syndrome lésionnel + sous-lésionnel ; IRM médullaire en urgence ; penser aux métastases.
  • Myasthénie : fatigabilité à l'effort corrigée au repos, ptosis/diplopie ; Ac anti-RAch, décrément ENMG ; rechercher un thymome.

À retenir absolument

  • SEP : critères de McDonald = dissémination spatiale ET temporelle.
  • Toute compression médullaire = IRM médullaire en urgence, ne jamais retarder.
  • Myasthénie : déficit variable/fatigable ; attention aux médicaments contre-indiqués (aminosides, curares…).
