Anémies : orientation diagnostique

  • Anémie = Hb < 13 g/dL (H) / < 12 g/dL (F) ; < 10,5 g/dL chez la femme enceinte.
  • Deux paramètres d'orientation : le VGM (micro / normo / macro) et les réticulocytes (régénérative / arégénérative).
  • Microcytaire → bilan martial : ferriprive (ferritine basse) vs inflammatoire (ferritine normale/haute, CRP↑) vs thalassémie (électrophorèse Hb).
  • Macrocytaire arégénérative → dosage B12 / folates ; myélodysplasie si carences éliminées.
  • Normocytaire régénérative → hémorragie ou hémolyse (haptoglobine↓, LDH↑, bilirubine libre↑, test de Coombs).
  • Devant une anémie arégénérative inexpliquée ou une pancytopénie → myélogramme.

À retenir absolument

  • Toujours coupler VGM + réticulocytes avant tout bilan étiologique.
  • Carence martiale = cause la plus fréquente : chercher un saignement digestif (fibroscopie/coloscopie) après 50 ans.
  • Hémolyse = triade haptoglobine effondrée, LDH élevées, bilirubine libre augmentée.
