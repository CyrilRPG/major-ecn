Ulcère gastro-duodénal : causes, diagnostic, traitement

ItemRepère
Deux causes principalesHelicobacter pylori (cause dominante, surtout ulcère duodénal) et AINS / aspirine
DiagnosticEndoscopie œso-gastro-duodénale avec biopsies : biopsies antrales + fundiques pour H. pylori, et biopsies systématiques des berges de l'ulcère gastrique (recherche de cancer)
Éradication d'H. pyloriTrithérapie : IPP + 2 antibiotiques (schéma probabiliste ou guidé par l'antibiogramme) ; contrôle de l'éradication à distance (test respiratoire à l'urée)
ComplicationsHémorragie digestive (la plus fréquente), perforation, sténose, transformation maligne (ulcère gastrique)
Contrôle endoscopiqueSystématique pour l'ulcère gastrique (cicatrisation + nouvelles biopsies pour éliminer un cancer) ; non nécessaire pour l'ulcère duodénal non compliqué

Pathologie gastro-duodénale et RGO

  • RGO typique = pyrosis + régurgitations ; sujet jeune sans signe d'alarme = diagnostic clinique, pas d'endoscopie.
  • Signes d'alarme (dysphagie, amaigrissement, anémie, âge > 50 ans, résistance aux IPP) = endoscopie indispensable.
  • Traitement du RGO = IPP + règles hygiéno-diététiques ; chirurgie anti-reflux (fundoplicature) dans les formes réfractaires.
  • Complications du RGO : œsophagite, sténose peptique, endobrachyœsophage (Barrett, précancéreux) → surveillance endoscopique.
  • Ulcère gastro-duodénal : deux causes = Helicobacter pylori et AINS.
  • Diagnostic = endoscopie + biopsies (H. pylori ; berges de l'ulcère gastrique pour éliminer un cancer).
  • Traitement = trithérapie d'éradication d'H. pylori (IPP + 2 antibiotiques) ; complications = hémorragie et perforation.
  • Ulcère gastrique = contrôle endoscopique de cicatrisation avec nouvelles biopsies (risque de cancer).

À retenir absolument

  • RGO typique sans signe d'alarme = IPP sans endoscopie ; signe d'alarme = endoscopie.
  • Ulcère gastro-duodénal = H. pylori + AINS ; endoscopie + biopsies + trithérapie d'éradication.
  • Ulcère gastrique = biopsies des berges + contrôle de cicatrisation (cancer).
