MAJOR EVC 
Révisions transversales, validations de spécialité, consolidation, renforcement approfondi, réévaluations, alertes et dashboard
1. Principe général
La plateforme doit distinguer 3 choses différentes :

1. Progression dans la formation
Le candidat avance dans les spécialités :

cardiologie ;

pneumologie ;

neurologie ;

pédiatrie ;

gériatrie ;

endocrinologie ;

etc.

Cela correspond au fait de regarder les cours, lire les fiches, faire les QCM d’entraînement, avancer dans les modules.

2. Maintien des acquis
Le candidat entretient les spécialités déjà étudiées grâce aux révisions transversales.

Ces révisions ne servent pas à découvrir de nouveaux cours, mais à éviter l’oubli.

3. Évaluations officielles
Ce sont elles qui donnent le vrai statut pédagogique d’une spécialité :

vert ;

orange ;

rouge.

Les évaluations officielles sont :

interrogation Major EVC de fin de spécialité ;

mini-évaluation après consolidation ;

nouvelle évaluation après renforcement approfondi ;

réévaluation après absence ;

épreuve blanche.

3. Fonctionnement de la révision du jour
La révision du jour pioche dans les spécialités déjà étudiées.

Chaque QCM doit être tagué au minimum par spécialité :

cardiologie ;

pneumologie ;

neurologie ;

endocrinologie ;

etc.

Le système doit privilégier :

QCM jamais vus ;

QCM déjà ratés ;

QCM anciens ;

spécialités fragiles ;

spécialités validées mais peu revues récemment.

9. Fin d’une spécialité
Lorsqu’un candidat termine une spécialité, par exemple Cardiologie, une interrogation officielle Major EVC devient disponible.

Elle doit être créée par l’équipe pédagogique.

Elle n’est pas générée automatiquement par la plateforme.

Format :

15 QCM ;

2 questions ouvertes ;

éventuellement un mini-cas clinique ;

durée : 15 à 20 minutes.

15. Règle finale de blocage
Ne pas bloquer durablement le candidat.

Blocage autorisé uniquement :

après 14 jours sans révision transversale ;

uniquement sur l’accès aux nouveaux contenus ;

les anciens contenus restent accessibles ;

le blocage est levé dès que la réévaluation est réalisée.

Même si la réévaluation est rouge, le candidat peut reprendre sa progression, mais la plateforme affiche des alertes fortes et l’équipe pédagogique est prévenue.

Objectif :

guider, alerter, accompagner, sans créer de frustration excessive.

POINT A PRENDRE EN COMPTE. 
Toute modification d'une note de spécialité passe obligatoirement par une évaluation officielle.

Les révisions transversales ne servent qu'à détecter un problème.

La nouvelle note officielle n'est attribuée qu'après :

une évaluation de fin de spécialité ;
une mini-évaluation après consolidation ;
une nouvelle évaluation après renforcement approfondi ;
une réévaluation ciblée suite à une baisse détectée ;
éventuellement une épreuve blanche spécialisée.
