# Annales EVC - Structure et guide d'utilisation

## Vue d'ensemble

Le dossier `Annales/` contient les sujets des **Épreuves de Vérification des Connaissances (EVC)** utilisés pour les ECN. Ces annales servent deux objectifs dans le générateur de fiches :

1. **Placement des marqueurs ★** : identifier les notions déjà tombées aux ECN
2. **Priorisation du contenu** : focaliser les fiches sur les points clés susceptibles de tomber

## Types d'épreuves

| Type | Sigle | Description | Format |
|------|-------|-------------|--------|
| Connaissances Fondamentales | **EVCF** | QCM / questions isolées théoriques | `EVCF.XX.DOC` |
| Connaissances Pratiques | **EVCP** | Dossiers cliniques progressifs | `EVCP.XX.DOC` |

`XX` = code spécialité (voir table ci-dessous).

## Comment accéder aux annales d'une spécialité

Pour une spécialité donnée (ex: Pneumologie = code **38**) :

### Fichiers DOC individuels
```
Annales/{dossier_année}/EVCF.38.DOC   (fondamentales)
Annales/{dossier_année}/EVCP.38.DOC   (pratiques/dossiers)
```

### Fichiers PDF compilés
Les PDF regroupent toutes les spécialités d'une année en un seul fichier. Les pages correspondant à une spécialité doivent être extraites manuellement.

## Règles d'utilisation pour le générateur

### Placement des ★ (déjà tombé aux ECN)
- Parcourir tous les fichiers `.38.DOC` (EVCF + EVCP) pour la pneumologie
- Identifier les notions, pathologies, médicaments, valeurs seuils questionnés
- Placer le marqueur ★ devant chaque notion retrouvée dans les annales

### Priorisation du contenu
- Les thèmes les plus fréquemment tombés doivent être développés en priorité
- Les dossiers cliniques (EVCP) indiquent les raisonnements attendus
- Les QCM (EVCF) identifient les connaissances ponctuelles à maîtriser
- Un sujet tombé plusieurs années = notion à très haut rendement (◆)

### Conventions de nommage
- `EVCF` = Épreuves de Vérification des Connaissances Fondamentales
- `EVCP` = Épreuves de Vérification des Connaissances Pratiques
- Le numéro après le point = code spécialité (cf. `Liste_specialites_EVC.pdf`)
- Les fichiers `.DOC` sont au format Microsoft Word 97-2003
